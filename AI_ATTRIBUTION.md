# AI Attribution

The NASA Space Apps Project Submission Guide permits AI tools when their use is clearly indicated. This file states where and how AI was used in ORION-MED // HEV-1.

## Team (human) contributions
- Project concept, name and identity (ORION-MED // HEV-1, "YOUR LIFE. OUR PRIORITY.").
- Product requirements and acceptance rules (ACK never clears a warning, missing data is never normal, offline-first, deterministic alerting, scientific honesty).
- System architecture: five layers, approved technology stack, module layout, API surface, alert state model, R.I.D.G.E. correlation concept, simulator scenarios, demonstration script.
- **Digital Human Twin artwork** (`frontend/src/modules/digital-twin/HumanTwin.tsx`, anatomical SVG): hand-made by the team.
- Action-Centric HUD concept (COMMAND screen) and the operational-readiness / EVA gate concept.
- Windows helper scripts `dev.bat`, `rebuild.bat`, `stop.bat` (stop.bat and dev.bat later fixed with AI assistance).
- Direction, review and acceptance of the generated implementation; local execution and testing.

## How AI-generated content is marked
- **Code:** every source file starts with an `AI-assisted (Claude, Anthropic)` header pointing to this file.
- **Audio:** `frontend/public/audio/*.wav` contain a RIFF INFO comment acknowledging AI-assisted generation; they are synthesized tones (`tools/generate_tones.py`), not recorded voices. Spoken announcements use the operating system's speech synthesizer at runtime.
- **Images:** the screenshots in `docs/screenshots/` are captures of the real running application (automated with Playwright), not AI-generated images.

## Data integrity
- No scientific data was generated by AI. NASA DONKI events are fetched live from api.nasa.gov and cached with provenance; OSDR references point to real, inspected datasets.
- All simulated telemetry is produced by the deterministic mission simulator, stored with `source = SIMULATED` and labeled `SIM` in the interface.
- The DONKI offline baseline (C2.4) is a placeholder explicitly labeled "not a NASA observation".
- No NASA logos, insignia or design elements are used.
